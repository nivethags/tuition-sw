differnce b/w normal function and arraow function 


function showArgs() {
    console.log(arguments); // Outputs: [1, 2, 3]
}
showArgs(1, 2, 3);


const showArgs = () => {
    console.log(arguments); // ❌ ERROR: arguments is not defined
};
showArgs(1, 2, 3);


✅ Solution: Use rest parameters (...args) in arrow functions instead:

javascript
Copy
Edit
const showArgs = (...args) => {
    console.log(args); // Outputs: [1, 2, 3]
};
showArgs(1, 2, 3);


2️⃣ Constructor Function Difference (new keyword)
A constructor function is used to create objects. Regular functions can be used as constructors, but arrow functions CANNOT because they don’t have their own this.

✅ Regular Function (Can be used with new)

function Person(name) {
    this.name = name;
}
const p = new Person("Alice");
console.log(p.name); // Alice


❌ Arrow Function (Cannot be used as a constructor)

const Person = (name) => {
    this.name = name;
};
const p = new Person("Alice"); // ❌ ERROR: Person is not a constructor
3️⃣ Implicit Return in Arrow Functions
Arrow functions allow implicit return, meaning you don’t need the return keyword for single expressions.

✅ Implicit Return (Shorter Syntax)

const add = (a, b) => a + b; // No need for {} or return
console.log(add(5, 3)); // 8


❌ Explicit Return (When Using {})
If you use {}, you MUST include return:


const add = (a, b) => { return a + b; };
console.log(add(5, 3)); // 8


If {} is used without return, the function will return undefined:

const add = (a, b) => { a + b; };
console.log(add(5, 3)); // undefined ❌


If you want to print or make changes to all elements selected with querySelectorAll(), you need to loop through them. 
Since querySelectorAll() returns a NodeList, you can use methods like forEach() or a for...of loop.

let elements = document.querySelectorAll(".myClass");

elements.forEach((element) => {
    console.log(element.innerText);  // Print each element's text
    element.style.color = "blue";    // Change text color to blue
});


let elements = document.querySelectorAll(".myClass");

for (let element of elements) {
    console.log(element.innerText);
    element.style.backgroundColor = "yellow";  // Change background color
}
